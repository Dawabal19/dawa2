========================================
  EthioAlibaba — Render Deploy Guide
========================================

1. GitHub ላይ አዲስ repo ይፍጠሩ (private ይመከራል)
2. እነዚህን ፋይሎች push ያድርጉ:
   - app.py
   - requirements.txt
   - templates/ (ሙሉ folder)
   - .env.example
   - README.md

3. https://dashboard.render.com → New → Web Service
   - Connect the GitHub repo
   - Runtime: Python 3
   - Build Command:
        pip install -r requirements.txt
   - Start Command:
        gunicorn app:app --bind 0.0.0.0:$PORT

4. Environment Variables (Render → Environment) ውስጥ ያክሉ:
   TELEGRAM_BOT_TOKEN = (የቦትዎ token)
   TELEGRAM_CHAT_ID   = (የእርስዎ chat id)
   SECRET_KEY         = (ረጅም random string)

5. Deploy ይጫኑ

6. ከተሳካ በኋላ Telegram webhook ያስቀምጡ:
   (በራስዎ ኮምፒውተር ላይ)
   python app.py set-webhook https://YOUR-APP-NAME.onrender.com

⚠️ ማሳሰቢያ:
- Render free tier sleep ይልላል (15 ደቂቃ inactivity)
- SQLite data በ restart ጊዜ ሊጠፋ ይችላል (free tier)
- ለ production PostgreSQL + paid plan ይመከራል
